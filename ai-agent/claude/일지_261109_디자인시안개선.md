## 요청·결정
- 요청: `design/index.html`(메인 홈페이지 시안)을 데스크톱/모바일(390px)로 확인해 개선점 10개를 제안 → 사용자가 **10개 전부 반영** 지시.
- 제약(사용자 지시): 섹션 구성(헤더→히어로→학습모드→고민→방법→루틴→커뮤니티→CTA→연락처→푸터→퀵메뉴) 유지, 색은 `:root` 변수 구조 유지.
- 범위: `design/` 폴더 안에서만 작업. Flask 앱(`templates/landing.html`)은 건드리지 않음. 시안의 앱 이식 여부는 미정.
- 참고 사이트 없음.

## 한 일
1. 모바일 헤더: 햄버거 메뉴로 전환. 158px → 65px. 로고·CTA 줄바꿈 방지(420px 이하는 "시작하기"만 표시).
2. 퀵메뉴: 1100px 이하에서는 "맨 위로"만 표시, 스크롤 400px 후 노출.
3. `section[id]` 에 `scroll-margin-top` (데스크톱 88px, 모바일 72px).
4. 대비: `--on-navy-2`, `--dot` 변수 추가. `.mode-no`·`.r-tag` 는 `--text-3`.
5. 슬라이더: 정지/재생 버튼, 마우스·포커스 시 일시정지, `prefers-reduced-motion` 이면 자동재생 끔, 점 터치영역 44px, `aria-current`, 자동재생 중 `aria-live=off`/정지 중 `polite`. 카드 목업은 `inert`.
6. 접근성: `:focus-visible`, 본문 바로가기 링크, `<main>`, 링크류 높이 44px(유틸 바 28px).
7. 모바일 학습모드 행 3열 그리드, 섹션 여백·카드 축소. 모바일 전체 높이 10,084 → 8,308px.
8. 내비: "서비스 소개" 삭제(중복), "레벨 테스트" → "고민 해결"(#faq). 퀵메뉴 "레벨테스트" 는 `#`(히어로 CTA 와 동일, 목적지 미정).
9. 폰트: Google Fonts 제거 → `design/fonts/` 로컬 번들(Noto Sans KR·Outfit 가변폰트 126개, 3.7MB, SIL OFL, `LICENSE.txt`). 외부 요청 0건 확인.
10. placeholder: 공지 문구는 히어로 문구 기반으로 작성, 연락처·운영시간·사업자 정보는 "준비 중/정식 오픈 시 안내" 로 대체(정보를 지어내지 않음).
