## 2. 결정 기록 (ADR-001: 데이터 저장소)
- **배경**: 현재는 CSV/JSON 로컬 파일(`data/words.csv`, `progress.json` 등). 11/16부터 여러 명이 동시에 접속하고, 사용자별 학습 기록과 관리자 통계가 필요함.
- **대안**: (A) CSV/JSON 유지 + 사용자별 파일 분리 / (B) SQLite 전환 / (C) 서버형 DB(PostgreSQL 등)
- **결정(제안)**: **(B) SQLite** — 표준 라이브러리 `sqlite3` 만 사용(의존성 추가 없음), 파일 1개라 배포·백업 간단, 동시 쓰기 충돌 위험이 CSV보다 낮음, 통계 집계 쿼리가 쉬움. 규모 확대 시 (C)로 이전 가능하도록 접근 코드를 `src/data/` 한 곳에 모은다.
- **결과**: 기존 CSV 업로드는 "가져오기" 기능으로 유지. 기존 `FileManager` 호출부 수정 필요.

## 3. 역할/화면 구조
| 영역 | 경로 | 화면 |
| :--- | :--- | :--- |

| 관리자 | `/admin/`, `/admin/words`, `/admin/users`, `/admin/settings` | 전체 통계 대시보드·단어 관리(CRUD, CSV)·사용자 관리·시험/전역 설정 (`/admin/stats` 는 대시보드로 통합) |

- 권한: 세션 로그인 + 역할(`user`/`admin`). `/admin/*` 는 `admin_required` 데코레이터로 보호. 비밀번호는 `werkzeug.security` 해시.

1. 사용자 로그인 → 대시보드(오늘 목표·진행률) → 플립카드 학습 → 시험 → 결과/리포트
