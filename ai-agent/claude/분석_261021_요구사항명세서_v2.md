5. 윈도우 종료 시 데이터 자동 저장

### 1.3 [FR-003] 학습 탭 (StudyTab)

**ID**: `FR-003`  
**제목**: 암기 학습 UI  
**설명**: 일일 단어 암기 기능을 위한 탭

**UI 컴포넌트**:
- QLabel (진도 정보)
- QProgressBar (완료율)
- QFrame (단어 표시 영역)
- QPushButton (O/X 버튼)
- QTableWidget (오늘의 단어 리스트)
- QLabel (성공률 표시)

**상세 기능**:

**3.1 진도 정보 표시**
- 현재 진도: "15일차 / 200일차"
- 전체 진도 프로그레스 바
- 오늘 학습 상태 아이콘

**3.2 단어 학습 영역**
- 큰 폰트(36pt)로 영단어 표시
- 그 아래 한글 해석 표시(24pt)
- 배경색으로 시각적 강조

**3.3 암기 여부 입력**
- O 버튼: "이 단어 외웠어요!" (초록색)
- X 버튼: "아직 못 외웠어요" (빨간색)
- 버튼 클릭 시 즉시 다음 단어로 진행

**3.4 실시간 피드백**
- "3/10 완료" 진행률 표시
- 오늘 성공률 실시간 계산 (80%)
- 학습 완료 시 축하 메시지

**3.5 오늘의 단어 리스트**
- 남은 단어 목록 (테이블)
- 단어별 암기 상태 표시
- 이전 단어 클릭 시 수정 가능

**상세 프로세스**:
```
Phase 1: 초기화
  1. 탭 클릭 시 progress.json 로드
  2. 현재 일차 확인
  3. 신규 + 복습 + 약점 단어 조합 (70/20/10 비율)
  4. 단어 목록 메모리에 로드

Phase 2: 학습 진행
  5. 첫 번째 단어 표시 (영단어, 해석)
  6. 사용자가 O 또는 X 선택
  7. 선택 즉시 기록 (메모리)
  8. 다음 단어로 자동 이동
  9. 3번~8번 반복

Phase 3: 완료
  10. 모든 단어 학습 완료 확인
  11. 결과를 study_log.csv에 append
  12. progress.json 업데이트 (current_day+1)
  13. 성공률 계산 및 표시
  14. "오늘 학습 완료!" 메시지 표시
```

### 1.4 [FR-004] 시험 탭 (TestTab)

**ID**: `FR-004`  
**제목**: 단어 시험 UI  
**설명**: 시험 설정 및 진행을 위한 탭

**설정 영역 UI**:
- QSpinBox (문제 수: 1~100)
- QComboBox (출제 모드: 한->영, 영->한, 혼합)
- QComboBox (출제 형식: 단답형, 4지선다형, OX형, 혼합)
- QPushButton (시험 시작)

**시험 진행 UI**:
- QProgressBar (진행 상황: 3/10)
- QLabel (문제 텍스트)
- QPushButton × 4 (선택지 - 4지선다형용)
- QLineEdit (입력 - 단답형용)
- QLabel (O/X 버튼 - OX형용)
- QPushButton (다음, 제출)

**상세 기능**:

**4.1 시험 설정 영역**
- 문제 수: 스핀박스 (1~100, 기본값 10)
- 출제 모드: 드롭다운 (한->영, 영->한, 혼합)
- 출제 형식: 드롭다운 (단답형, 4지선다형, OX형, 혼합)
- 시험 시작 버튼

**4.2 시험 진행**
```
Phase 1: 문제 출제
  1. 가중치 기반 단어 선택 (알고리즘)
  2. 형식 결정 (혼합이면 각 문제마다 랜덤)
  3. 첫 문제 표시

Phase 2: 답변 입력
  4. 문제 텍스트 표시 (큰 폰트)
  5. 형식에 따라 UI 표시
     - 단답형: QLineEdit (텍스트 입력)
     - 4지선다형: QPushButton×4 (선택지)
     - OX형: O/X 버튼
  6. 진행률 표시 (3/10)
  7. 사용자 답변 입력

Phase 3: 채점
  8. 정오답 판정 (grade_answer 함수)
  9. 결과 즉시 표시 (초록/빨강 색깔)
  10. 정답 공개
  11. [다음 문제] 버튼 활성화

Phase 4: 반복 및 완료
  12. 2번~11번 반복 (모든 문제)
  13. 마지막 문제 답변 후 [채점 완료] 클릭
  14. 시험 결과 페이지 표시
  15. 점수, 정오답 상세 표시
  16. test_log.csv에 append
  17. [다시 시험] 또는 [통계 보기] 버튼
```

**4.3 시험 결과 표시**
- 총 점수: 80점 (8/10)
- 문제별 상세 (정오답, 사용자 답변, 정답)
- 약점 단어 분석 (이번 시험에서 틀린 단어)

### 1.5 [FR-005] 통계 탭 (ReportTab)

**ID**: `FR-005`  
**제목**: 학습 통계 및 보고서  
**설명**: 그래프와 차트로 학습 통계 시각화

**UI 컴포넌트**:

- QProgressBar (학습율, 암기율, 시험 평균)
- MplCanvas (matplotlib 차트)
  - 최근 7일 시험 성적 (라인 차트)
  - 약점 단어 TOP10 (막대 차트)
  - 시험 정답률 분포 (파이 차트)

**기능**:
```
1. 학습 진도 표시
   - 15일차 / 200일차
   - 완료율: 7.5% 프로그레스 바

2. 암기 성과
   - 총 시도: 150회
   - 성공: 131회
   - 성공률: 87.5% 프로그레스 바

3. 시험 성과
   - 응시 횟수: 5회
   - 평균 점수: 78.4점 (프로그레스 바)
   - 최고/최저: 85 / 70점

4. 그래프 표시
   - 최근 7일 성적 추이
   - 약점 단어 랭킹 TOP10
   - 시험 통과율 분포

5. CSV로 내보내기 버튼
6. 보고서 인쇄 버튼
```

   - CSV, HTML, PDF 형식
   - reports/ 디렉토리에 저장
