# 스마트 보카 UI/UX 설계서

**파일 위치**: `ai-agent/claude/설계_261111_UI설계_v1.0.md`
**작성일**: 2026-11-11
**버전**: v1.0
**설명**: 사용자 인터페이스 레이아웃, 사용자 경험 흐름도. 프로세스·기능 분해도를 기반으로 화면 설계. 현행 `templates/` 파일을 역분석.

---

## 0. 디자인 원칙

1. **사용자 중심**: 직관적 네비게이션, 학습·시험·통계의 주요 기능 우선 노출
2. **반응형**: 모바일(480px↑), 태블릿, 데스크톱 지원
3. **접근성**: 한국어, ARIA 레이블, 충분한 대비도
4. **게임화**: 시각적 진행률, XP·레벨 강조
5. **일관성**: 버튼·컬러·타이포그래피 통일

## 1. 화면 맵 (Site Map)

```
홈페이지
│
├── 비로그인 사용자
│   ├── 랜딩 페이지 (/)
│   ├── 로그인 (/login)
│   └── 회원가입 (/register)
│
├── 로그인 사용자
│   ├── 대시보드 (/) — 진행률, 오늘의 학습
│   ├── 학습 (/study) — 일일 단어 학습
│   ├── 시험 (/test) — 시험 풀이
│   ├── 통계 (/report) — 차트, CSV 내보내기
│   ├── 리그 (/league) — 주간 순위
│   ├── 설정 (/settings) — 개인 설정
│   └── 로그아웃
│
└── 관리자
    ├── 관리자 대시보드 (/admin/)
    ├── 단어 관리 (/admin/words)
    │   ├── 단어 목록 (검색·페이지)
    │   ├── 단어 추가 (모달/폼)
    │   ├── 단어 수정 (모달/폼)
    │   ├── 단어 삭제 (확인)
    │   ├── CSV 가져오기 (/admin/words/import)
    │   └── CSV 내보내기 (/admin/words/export)
    ├── 사용자 관리 (/admin/users)
    │   ├── 사용자 목록 (검색·페이지)
    │   ├── 역할 변경
    │   ├── 활성/비활성화
    │   ├── 비밀번호 재설정
    │   └── 사용자 삭제 (확인)
    └── 설정 (/admin/settings)
        ├── 전체 학습 일수
        ├── 최대 시험 문제 수
        └── 최대 하루 학습량
```

## 2. 사용자 화면 상세 설계

### 2.1 랜딩 페이지 (/)

**대상**: 비로그인 사용자
**목표**: 서비스 소개, 로그인/가입 유도

**레이아웃**:
```
┌─────────────────────────────────────────┐
│ 헤더 (로고 | 로그인 | 가입)              │
├─────────────────────────────────────────┤
│ 히어로 섹션                              │
│ ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  │
│ 제목: "매일 단어, 스마트하게 학습"        │
│ 설명: 한 문장 소개                       │
│ [지금 시작] [로그인]                     │
├─────────────────────────────────────────┤
│ 통계 카드                                │
│ ┌────────┬────────┬────────┬────────┐   │
│ │ 단어수 │ 학습자 │학습한수│ 시험수 │   │
│ │ 1200  │  50    │ 25K   │ 15K    │   │
│ └────────┴────────┴────────┴────────┘   │
├─────────────────────────────────────────┤
│ 기능 소개 섹션                            │
│ ┌──────────┐ ┌──────────┐ ┌──────────┐ │
│ │학습       │ │시험      │ │통계      │ │
│ │아이콘    │ │아이콘   │ │아이콘   │ │
│ │설명      │ │설명     │ │설명     │ │
│ └──────────┘ └──────────┘ └──────────┘ │
├─────────────────────────────────────────┤
│ 푸터 (저작권, 링크)                      │
└─────────────────────────────────────────┘
```

**구성 요소**:
- 헤더: 로고, 로그인/가입 버튼
- 히어로 섹션: 제목, 설명, CTA 버튼 2개
- 통계 카드: 실시간 DB 수치 (단어 수, 학습자 수, 학습한 단어 합계, 시험 수)
- 기능 소개: 3개 카드 (학습, 시험, 통계)
- 푸터

**구현 파일**: `landing.html`

---

### 2.2 로그인 / 회원가입

**대상**: 비로그인 사용자
**목표**: 계정 관리

#### 로그인 (/login)

**레이아웃**:
```
┌──────────────────────┐
│ 중앙 카드 (너비 400px)│
├──────────────────────┤
│ 로고 + "로그인"       │
├──────────────────────┤
│ [아이디] 텍스트 입력  │
│ [비밀번호] 입력      │
│ [로그인] 버튼        │
├──────────────────────┤
│ "가입하기" 링크      │
└──────────────────────┘
```

**필드**:
- `username`: 텍스트 입력
- `password`: 비밀번호 입력
- CSRF 토큰: 숨김 필드

**오류 표시**:
- "아이디/비밀번호가 틀렸습니다" (통합 메시지)
- "로그인 시도가 너무 많습니다" (제한 시)

**구현 파일**: `login.html`, `auth_base.html`

#### 회원가입 (/register)

**레이아웃**: 로그인과 유사

**필드**:
- `username`: 3~20자, 영문·숫자·밑줄
- `password`: 6자 이상
- `password_confirm`: 일치 확인
- [가입] 버튼

### 2.3 대시보드 (/)

**대상**: 로그인 사용자
**목표**: 학습 진도 한눈에 보기, 오늘의 학습 유도

**레이아웃**:
```
┌─────────────────────────────────────────────┐
│ 상단 네비게이션 (메뉴, 사용자 정보, 로그아웃) │
├─────────────────────────────────────────────┤
│ 진행 요약 섹션 (카드)                        │
│ ┌──────────────┬──────────────┬────────────┐│
│ │ 레벨 N       │ XP: XXXX/YYY │ Streak: D일 ││
│ │ [████░░░░░░] │              │            ││
│ └──────────────┴──────────────┴────────────┘│
├─────────────────────────────────────────────┤
│ 오늘의 학습 섹션                            │
│ ┌─────────────────────────────────────────┐ │
│ │ 목표: 50개                              │ │
│ │ 학습함: X개                             │ │
│ │ [학습 시작] 버튼                        │ │
│ └─────────────────────────────────────────┘ │
├─────────────────────────────────────────────┤
│ 최근 통계 (카드 3개)                        │
│ ┌──────┬──────┬──────┐                     │
│ │ 학습 │ 시험 │마스터│                     │
│ │ 15일 │ 8회  │ 120  │                     │
│ └──────┴──────┴──────┘                     │
└─────────────────────────────────────────────┘
```

**구성 요소**:
- 상단 네비 (메뉴, 사용자명, 로그아웃)
- 진행 요약 카드 (레벨, XP 진행률, Streak)
- 오늘의 학습 (목표, 진행률, [학습 시작] 버튼)
- 최근 통계 (학습 일수, 시험 응시, 마스터 단어)

**구현 파일**: `dashboard.html`, `base.html`

**관련 요구사항**: FR-202, FR-203, FR-204

### 2.4 학습 (/study)

**대상**: 로그인 사용자
**목표**: 일일 단어 학습

**레이아웃**:
```
┌─────────────────────────────────────────┐
│ 제목: "오늘의 학습"                      │
│ 진행 바: [████████░░] 8/10               │
├─────────────────────────────────────────┤
│ 단어 카드 (큰 폰트)                      │
│ ┌─────────────────────────────────────┐ │
│ │ 영단어: APPLE                       │ │
│ │ 뜻: 사과                            │ │
│ │                                     │ │
│ │ [외웠음 ✓] [아직 ✗]                 │ │
│ └─────────────────────────────────────┘ │
├─────────────────────────────────────────┤
│ [다음]                                   │
│ (마지막 단어면 [학습 완료])              │
└─────────────────────────────────────────┘
```

**구성 요소**:
- 제목
- 진행 바 (현재/전체)
- 단어 카드 (영단어, 뜻)
- 2개 버튼 ([외웠음], [아직])
- 다음 버튼

**인터랙션**:
1. 단어 표시
2. 사용자 선택 ([외웠음] 또는 [아직])
3. 진행 바 업데이트
4. 다음 단어로 (또는 완료)

**구현 파일**: `study.html`, `static/js/study.js`

**관련 요구사항**: FR-301, FR-302, FR-303

### 2.5 시험 (/test)

**대상**: 로그인 사용자
**목표**: 단어 시험

#### 시험 설정 화면

**레이아웃**:
```
┌─────────────────────────────────────────┐
│ 제목: "시험 시작"                        │
├─────────────────────────────────────────┤
│ 문제 수                                 │
│ [정수 입력, 기본 20, 최대 50]            │
│                                         │
│ 출제 모드                               │
│ ○ 한→영  ○ 영→한  ○ 혼합               │
│                                         │
│ 출제 형식                               │
│ ☑ 단답형  ☑ 4지선다  ☑ OX  ☑ 빈칸     │
│                                         │
│ [시험 시작]                             │
└─────────────────────────────────────────┘
```

**필드**:
- 문제 수: 숫자 입력 (1~max_test_problems)
- 출제 모드: 라디오 버튼 3개
- 출제 형식: 체크박스 4개 (또는 혼합 옵션)

#### 시험 진행 화면

**레이아웃**:
```
┌─────────────────────────────────────────┐
│ 진행: [████░░░░] 3/10                    │
├─────────────────────────────────────────┤
│ 문제 3                                  │
│ "사과를 영어로?"                        │
├─────────────────────────────────────────┤
│ 형식별 입력 (예: 단답형)                │
│ [텍스트 입력]                           │
│                                         │
│ 또는 (예: 4지선다)                      │
│ ○ apple  ○ orange  ○ banana  ○ grape  │
│                                         │
│ [제출]                                  │
├─────────────────────────────────────────┤
│ (정답/오답 표시, 정답 노출)             │
│ "정답: apple"                           │
│ [다음]                                  │
└─────────────────────────────────────────┘
```

**인터랙션**:
1. 시험 설정 선택
2. 첫 문제 표시
3. 답 입력 → [제출]
4. 즉시 채점 + 정답 표시
5. [다음] → 다음 문제

#### 시험 결과 화면

**레이아웃**:
```
┌─────────────────────────────────────────┐
│ 시험 완료!                              │
├─────────────────────────────────────────┤
│ 점수: 85/100                            │
│ 정답: 8/10                              │
│ 획득 XP: +120                           │
│ 레벨 업! → Level 5                     │
├─────────────────────────────────────────┤
│ [통계로 가기] [다시 풀기]               │
└─────────────────────────────────────────┘
```

**구현 파일**: `test.html`, `static/js/test.js`, `problem.html`

## 9. 사용자 흐름 (User Journey)

### 9.1 "새 사용자의 첫 학습" 시나리오

```
1. 랜딩 페이지 방문
   ↓ [지금 시작]
2. 회원가입 화면
   - 아이디, 비밀번호 입력
   ↓ [가입]
3. 로그인 화면 (자동 리다이렉트 가능)
   - 아이디, 비밀번호 입력
   ↓ [로그인]
4. 대시보드
   - 레벨 1, 0 XP, 오늘 학습 안 함
   ↓ [학습 시작]
5. 학습 화면
   - 일일 50개 단어 학습
   - 각 단어마다 [외웠음]/[아직] 선택
   ↓ (완료)
6. 학습 완료
   - XP +XX, 진행률 업데이트
   ↓
7. 대시보드로 자동 리다이렉트
   - 통계 반영됨
```

### 9.2 "시험 풀기" 시나리오

```
1. 대시보드 또는 메뉴에서 [시험]
2. 시험 설정 화면
   - 문제 수: 20, 모드: 혼합, 형식: 혼합 선택
   ↓ [시험 시작]
3. 문제 1/20 화면
   - 문제: "사과를 영어로?"
   - 입력: "apple"
   ↓ [제출]
4. 채점 결과
   - "정답: apple" 표시
   ↓ [다음]
5. 문제 2~20 반복
6. 시험 완료
   - 점수: 85점, XP +180 획득
   ↓ [통계로 가기]
7. 통계 페이지
   - 시험 성적 반영됨
```
