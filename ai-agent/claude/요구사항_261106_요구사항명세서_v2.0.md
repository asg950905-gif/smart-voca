## 3. 비기능 요구사항 (NFR)

| ID | 분류 | 요구사항 | 근거·구현 | 상태 |
|---|---|---|---|---|

| NFR-002 | 보안 | 세션 쿠키는 HttpOnly, SameSite=Lax. HTTPS 배포 시 `SESSION_COOKIE_SECURE=1`. 로그인 시 세션을 새로 시작한다(세션 고정 방지). 유지 기간 7일. | `app.create_app`, `auth_routes.login` | 구현 |

## 5. 알려진 제약·미해결 사항

1. 로그인 시도 제한이 프로세스 메모리에 있다. 서버를 재시작하면 초기화되고, 프로세스가 여러 개이면 공유되지 않는다. (Gunicorn 다중 워커 전환 시 DB·Redis 로 이동 필요)
2. 비밀번호 찾기, 이메일, 아이디 변경, 사용자의 계정 삭제 기능이 없다.
3. 시험 정답 비교는 단순 문자열 일치라 동의어·여러 뜻을 인정하지 않는다.
4. DB 마이그레이션 수단이 없다. 스키마 변경 시 시연 DB 는 `--reset` 으로 재생성한다.
5. NFR-013(성능) 은 측정 근거가 없다.
