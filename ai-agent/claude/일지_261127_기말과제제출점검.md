## 점검에서 찾은 핵심 (상세는 채팅 보고)

- Dockerfile·.dockerignore·.gitattributes·.github/workflows 없음. gunicorn 미설치.
- `app.py` 는 `DATA_DIR`(기본 `/app/data` 에 해당) 를 쓰고 `DB_PATH` 를 읽지 않는다 → UID 10001 컨테이너에서 쓰기 실패 예상.
- 서버 nginx 의 sub_filter 는 `fetch('/` 형태만 고친다. 우리 JS 는 `api('/api/...')` 래퍼라 **API 호출이 하위 경로에서 깨진다** (check workflow 는 첫 화면 링크만 보므로 green 이어도 시연에서 실패).
- 빈 DB 로 시작하면 관리자 계정이 없다(환경변수 `ADMIN_*` 있을 때만 생성) → 단어 등록·CSV 가져오기 불가.
- CSV 가져오기는 헤더 `english,korean` 만 받는다 → 제공 CSV(`영단어,뜻`) 불가.
- Day 진도·암기 이력(단어·Day 단위)·시험 문항별 이력 테이블이 없다.
- 커밋 15개(10/28·11/04·11/11)의 작성자 이메일이 `user@example.com`.
