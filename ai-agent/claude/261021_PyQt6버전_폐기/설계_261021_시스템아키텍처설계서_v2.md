## 1. 아키텍처 개요

### 1.1 아키텍처 패턴

**선택 패턴**: 레이어드 아키텍처 (Layered Architecture)

```
┌─────────────────────────────────────────┐
│         Presentation Layer              │
│     (PyQt6 GUI - MainWindow)            │
│  ├─ StudyTab, TestTab, ReportTab        │
│  └─ Dialogs, Menus, StatusBar           │
├─────────────────────────────────────────┤
│      Business Logic Layer               │
│   (Manager Classes & Engines)           │
│  ├─ WordManager                         │
│  ├─ StudyManager                        │
│  ├─ TestEngine                          │
│  └─ ReportGenerator                     │
├─────────────────────────────────────────┤
│       Data Access Layer                 │
│   (File I/O & Persistence)              │
│  ├─ CSVHandler                          │
│  ├─ JSONHandler                         │
│  └─ FileManager                         │
├─────────────────────────────────────────┤
│      Persistence Layer                  │
│   (Local File System)                   │
│  ├─ data/words.csv                      │
│  ├─ data/progress.json                  │
│  ├─ data/study_log.csv                  │
│  └─ data/test_log.csv                   │
└─────────────────────────────────────────┘
```

### 1.2 설계 원칙

```
✓ 계층 분리: UI ↔ 비즈니스 로직 ↔ 데이터
✓ 단일 책임: 각 클래스는 하나의 역할만
✓ 의존성 역전: 추상화에 의존 (인터페이스)
✓ 재사용성: v1.0 로직 활용
✓ 테스트 용이: 각 계층 독립 테스트 가능
```

## 3. Signal/Slot 메커니즘

### 3.1 신호 정의 (Signals)

```python
# MainWindow
class MainWindow(QMainWindow):
    tab_changed = pyqtSignal(int)           # 탭 변경
    settings_changed = pyqtSignal(dict)     # 설정 변경
    file_opened = pyqtSignal(str)           # 파일 열림

# StudyTab
class StudyTab(QWidget):
    progress_updated = pyqtSignal(int, int) # (current_day, total_days)
    study_completed = pyqtSignal()          # 학습 완료
    word_changed = pyqtSignal(str, str)     # (english, korean)
    success_rate_changed = pyqtSignal(float)# (rate %)

# TestTab
class TestTab(QWidget):
    test_started = pyqtSignal()             # 시험 시작
    test_completed = pyqtSignal(float)      # (score)
    problem_updated = pyqtSignal(int, int)  # (current, total)
    answer_graded = pyqtSignal(bool)        # (is_correct)

# ReportTab
class ReportTab(QWidget):
    charts_generated = pyqtSignal()         # 차트 생성 완료
```

### 3.2 슬롯 연결 (Slot Connections)


## 4. 이벤트 처리 흐름

### 4.1 학습 탭 이벤트 흐름

```
사용자 클릭 (O 또는 X 버튼)
  ↓
StudyTab.on_ok_clicked() / on_x_clicked()
  ↓
result 기록 (메모리)
  ↓
StudyManager.record_study() 호출
  ↓
progress.json 업데이트
study_log.csv append
  ↓
progress_updated 신호 발생
  ↓
MainWindow.update_status_bar() 호출
  ↓
상태바 업데이트 (진도, 성공률)
  ↓
다음 단어 표시
  └─ word_changed 신호 발생
     └─ UI 업데이트
```

### 4.2 시험 탭 이벤트 흐름

```
[시험 시작] 버튼 클릭
  ↓
TestTab.on_start_test()
  ↓
TestEngine.select_words_weighted()
  ↓
첫 번째 문제 생성 및 표시
  ↓
사용자 답변 입력
  ↓
[제출] 버튼 클릭
  ↓
TestEngine.grade_answer()
  ↓
정오답 표시
answer_graded 신호 발생
  ↓
다음 문제 또는 시험 완료
  ↓
모든 문제 완료 시
  ↓
TestEngine.record_test()
  ↓
test_log.csv append
  ↓
test_completed 신호 (점수 포함)
  ↓
MainWindow.show_result_dialog()
  ↓
결과 표시 + ReportTab 자동 새로고침
```

### 4.3 통계 탭 이벤트 흐름

```
ReportTab 진입 또는 새로고침
  ↓
ReportTab.load_statistics()
  ↓
ReportGenerator.calculate_statistics()
  ↓
학습 통계 계산
암기 성공률 계산
시험 평균 점수 계산
약점 단어 분석
  ↓
ReportGenerator.generate_charts()
  ↓
matplotlib으로 차트 생성
  ├─ 최근 7일 시험 성적 (라인 차트)
  ├─ 약점 단어 TOP10 (막대 차트)
  └─ 시험 정답률 분포 (파이 차트)
  ↓
charts_generated 신호 발생
  ↓
UI에 차트 표시
```

## 5. 스레드 관리

### 5.1 백그라운드 작업

```python
# 차트 생성이나 대용량 파일 로드는 별도 스레드에서

class ChartWorker(QRunnable):
    """차트 생성 작업"""
    
    def run(self):
        # 시간이 걸리는 작업
        charts = ReportGenerator.generate_charts()
        # 신호 발생
        self.signals.finished.emit(charts)

# MainWindow에서 사용
self.thread_pool = QThreadPool()
worker = ChartWorker()
self.thread_pool.start(worker)
```

### 5.2 이점
```
✓ UI 반응성 유지
✓ 대용량 데이터 처리 중에도 사용자 입력 가능
✓ 진행 표시 (프로그레스 바) 가능
```

## 7. 에러 처리 전략

### 7.1 예외 처리 계층

```python
try:
    # 비즈니스 로직
    result = StudyManager.get_daily_words()
except FileNotFoundError:
    # 파일 없음 → 대화상자 표시 → 파일 선택 요청
    self.show_file_dialog()
except ValueError:
    # 데이터 형식 오류 → 사용자 메시지
    self.show_error("데이터 형식이 올바르지 않습니다")
except Exception as e:
    # 예상 외 오류 → 로그 기록 + 사용자 알림
    logger.error(f"Unexpected error: {e}")
    self.show_error("오류가 발생했습니다. 로그를 확인하세요.")
```
