## 2. 테이블/파일 설계

### 2.1 words.csv (단어 사전)

**용도**: 학습할 모든 단어 저장 (읽기 전용)

**구조**:
```
번호,영단어,한국어해석,품사,난이도
1,apple,사과,noun,1
2,book,책,noun,1
3,beautiful,아름다운,adjective,1
...
```

**필드 명세**:

| 필드명 | 타입 | 설명 | 예시 |
|--------|------|------|------|
| **번호** | INT | 단어 고유 ID (PK) | 1 |
| **영단어** | VARCHAR | 영어 단어 | apple |
| **한국어해석** | VARCHAR | 한글 의미 | 사과 |
| **품사** | VARCHAR | 단어 품사 | noun, verb, adjective |
| **난이도** | INT | 1~3 (쉬움~어려움) | 1, 2, 3 |

**데이터 특성**:
- 총 300개 단어 (v1.0 재사용)
- 난이도별 분포: 1등급(쉬움) ~60%, 2등급 ~35%, 3등급(어려움) ~5%
- 품사 분포: noun 60%, adjective 30%, verb 10%
- 인코딩: UTF-8

**로드 시점**: 애플리케이션 시작 시 메모리에 로드
**저장 정책**: 쓰기 불가 (마스터 데이터)

### 2.2 progress.json (학습 진도)

**용途**: 현재 학습 상태 추적

**구조**:
```json
{
  "current_day": 15,
  "total_days": 30,
  "daily_target": 10,
  "learned_words": [1, 2, 3, 4, 5],
  "weak_words": [10, 25, 42],
  "last_updated": "2026-10-21 14:30:00",
  "learning_rate": 0.85,
  "start_date": "2026-09-07"
}
```

**필드 명세**:

| 필드명 | 타입 | 설명 | 예시 |
|--------|------|------|------|
| **current_day** | INT | 현재 진행 일차 | 15 |
| **total_days** | INT | 전체 계획 일차 | 30 |
| **daily_target** | INT | 하루 학습 단어 수 | 10 |
| **learned_words** | ARRAY[INT] | 암기 완료한 단어 ID 목록 | [1, 2, 3...] |
| **weak_words** | ARRAY[INT] | 약점 단어 ID 목록 (시험 오답) | [10, 25...] |
| **last_updated** | DATETIME | 마지막 업데이트 시각 | 2026-10-21 14:30:00 |
| **learning_rate** | FLOAT | 암기 성공률 (0.0~1.0) | 0.85 |
| **start_date** | DATE | 학습 시작 날짜 | 2026-09-07 |

**특성**:
- 싱글톤 (1개만 존재)
- 매 학습/시험 후 즉시 업데이트
- 메모리에 로드 (성능)
- 파일은 동기화용 (백업)

**업데이트 타이밍**:
```
학습 완료 시 → progress 업데이트
시험 완료 시 → weak_words 추가/업데이트
매 구간 마다 → 파일에 저장
```

**구조**:
```
날짜,시간,일차,단어ID,영단어,한글해석,결과,소요시간(초),성공률
2026-10-21,14:30:00,15,1,apple,사과,O,2,0.85
2026-10-21,14:31:00,15,2,book,책,O,3,0.85

...
```

**필드 명세**:

| 필드명 | 타입 | 설명 | 예시 |
|--------|------|------|------|
| **날짜** | DATE | YYYY-MM-DD | 2026-10-21 |
| **시간** | TIME | HH:MM:SS | 14:30:00 |
| **일차** | INT | 학습 일차 | 15 |
| **단어ID** | INT | words.csv의 번호 | 1 |
| **영단어** | VARCHAR | 영어 단어 | apple |
| **한글해석** | VARCHAR | 한글 뜻 | 사과 |
| **결과** | CHAR(1) | O 또는 X | O |
| **소요시간** | INT | 초 단위 | 2 |
| **성공률** | FLOAT | 누적 오늘 성공률 | 0.85 |

**특성**:
- Append-only (추가만 가능)
- 매 학습마다 행 추가

- 통계 생성용 (SELECT 주로 사용)

**쿼리 예시**:
```sql

-- 특정 단어의 학습 이력
SELECT * FROM study_log WHERE 단어ID = 1 ORDER BY 날짜 DESC

-- 주간 성공률
SELECT 날짜, AVG(성공률) FROM study_log 
  GROUP BY 날짜 
  ORDER BY 날짜 DESC LIMIT 7
```

# 데이터 로드 시 검증

class DataValidator:
    @staticmethod
    def validate_words(words: List[Word]):
        """words 테이블 검증"""
        assert len(words) > 0, "단어가 없음"
        for word in words:
            assert word.word_id > 0, f"ID 오류: {word}"
            assert len(word.english) > 0, f"영단어 없음: {word}"
            assert 1 <= word.difficulty <= 3, f"난이도 범위 오류: {word}"
        return True
    
    @staticmethod
    def validate_progress(progress: Progress):
        """progress 데이터 검증"""
        assert progress.current_day >= 1, "일차 오류"
        assert progress.current_day <= progress.total_days, "일차 초과"
        assert progress.daily_target > 0, "일일 목표 오류"
        assert 0 <= progress.learning_rate <= 1.0, "학습률 범위 오류"
        return True

### 8.1 읽기 최적화

```python
# words.csv는 메모리에 유지 (빠른 접근)
# → 시작 시만 파일 읽기

class WordManager:
    def __init__(self):
        self.words = self._load_words_once()
    
    def _load_words_once(self):
        """한 번만 로드"""
        df = pd.read_csv('data/words.csv', encoding='utf-8-sig')
        return {row['번호']: Word(**row) for _, row in df.iterrows()}
    
    def get_word(self, word_id):
        """O(1) 접근"""
        return self.words.get(word_id)
```

### 8.2 쓰기 최적화

```python
# append 작업은 배치 처리 (버퍼링)

class FileManager:
    def __init__(self):
        self.write_buffer = []
    
    def append_record(self, record):
        """버퍼에 추가"""
        self.write_buffer.append(record)
        
        # 버퍼가 가득 차면 한 번에 쓰기
        if len(self.write_buffer) >= 10:
            self.flush()
    
    def flush(self):
        """버퍼를 파일에 한 번에 쓰기"""
        if self.write_buffer:
            df = pd.DataFrame(self.write_buffer)
            df.to_csv('data/study_log.csv', mode='a', 
                     header=False, index=False)
            self.write_buffer = []
```

### 9.1 필요한 메트릭

```python
class Statistics:
    """학습 통계 계산"""
    
    @staticmethod
    def get_learning_progress():
        """학습 진도"""
        return {
            'current_day': progress.current_day,
            'total_days': progress.total_days,
            'percentage': (progress.current_day / progress.total_days) * 100
        }
    
    @staticmethod
    def get_success_rate(days=1):
        """최근 N일 암기 성공률"""
        recent = study_log[study_log['날짜'] >= (date.today() - timedelta(days=days))]
        return recent['결과'].value_counts()['O'] / len(recent)
    
    @staticmethod
    def get_test_average(days=7):
        """최근 7일 시험 평균"""
        recent = test_log[test_log['날짜'] >= (date.today() - timedelta(days=days))]
        return recent['점수'].mean()
    
    @staticmethod
    def get_weak_words(top_n=10):
        """약점 단어 TOP N"""
        weak = test_log[test_log['정답'] == 'X']
        return weak['단어ID'].value_counts().head(top_n).to_dict()
```
