## 1. 기능 요구사항 (FR)

### 1.1 [FR-001] 웹 메인 페이지 (대시보드)

**ID**: `FR-001`  
**제목**: 애플리케이션 홈 페이지  
**설명**: 학습 진도, 오늘 상태, 메뉴를 한눈에 보는 대시보드

**페이지 구성**:
- 타이틀: "smart-voca - 영어 단어 학습"
- 진도 정보 카드
  - 현재 진도: "15일차 / 200일차"
  - 진도율 프로그레스 바
- 오늘 학습 상태
  - 오늘 학습 여부 (O/X)
  - 성공률 표시
- 빠른 링크 (학습, 시험, 통계, 설정)

**입출력**:
- 입력: 없음
- 출력: HTML 페이지

---

### 1.2 [FR-002] 파일 업로드 페이지

**ID**: `FR-002`  
**제목**: 단어 CSV 파일 업로드  
**설명**: 초기 단어 데이터 로드

**기능**:
```
1. 파일 선택 인터페이스
2. CSV 형식 검증
3. 데이터 로드 및 저장
4. 성공/실패 메시지
```

---

### 1.3 [FR-003] 학습 페이지

**ID**: `FR-003`  
**제목**: 매일 단어 암기  
**설명**: 일일 단어 학습 기능

**페이지 요소**:
- 진도 표시
  - "3/10 완료"
  - 프로그레스 바
- 단어 표시
  - 큰 폰트 영단어
  - 한글 뜻
- 암기 여부 선택
  - [O 외웠어요!] 버튼 (초록)
  - [X 아직] 버튼 (빨강)
- 실시간 성공률

**프로세스**:
```
1. 오늘의 단어 로드
2. 첫 번째 단어 표시
3. O 또는 X 선택
4. 다음 단어 표시
5. 모두 완료 시 결과 저장
```

---

### 1.4 [FR-004] 시험 페이지

**ID**: `FR-004`  
**제목**: 단어 시험  
**설명**: 사용자 맞춤 시험

**설정 영역**:
- 문제 수 (스핀박스 또는 드롭다운)
- 출제 모드 (한→영, 영→한, 혼합)
- 출제 형식 (단답형, 4지선다형, OX형)
- [시험 시작] 버튼

**시험 진행**:
- 문제 번호 표시 (1/10)
- 문제 텍스트
- 답변 입력 영역 (형식에 따라)
- [제출] 버튼
- 정오답 즉시 표시
- [다음 문제] 버튼

**결과 페이지**:
- 총 점수
- 정오답 상세
- 약점 단어 분석

---

### 1.5 [FR-005] 통계 페이지

**ID**: `FR-005`  
**제목**: 학습 통계 및 차트  
**설명**: 학습 진도와 성과를 그래프로 시각화

**표시 요소**:
1. 요약 통계 (카드)
   - 학습 진도 (일차/총일차)
   - 암기 성공률 (%)
   - 시험 응시 횟수
   - 시험 평균 점수

2. 그래프
   - 최근 7일 시험 성적 (라인 차트)
   - 약점 단어 TOP10 (막대 차트)
   - 시험 통과율 분포 (파이 차트)

3. 버튼
   - [CSV 내보내기] - 통계를 CSV로 다운로드

---

### 1.6 [FR-006] 설정 페이지

**ID**: `FR-006`  
**제목**: 사용자 설정  
**설명**: 학습 옵션과 앱 설정

**설정 항목**:
1. 학습 설정
   - 일일 학습 단어 수 (스핀박스)
   
2. 표시 설정
   - 다크 모드 토글
   - 테마 선택
   - 폰트 크기

3. 데이터 관리
   - [진도 초기화] 버튼
   - [모든 데이터 초기화] 버튼 (경고)

---

### 1.7 [FR-007] 네비게이션

**ID**: `FR-007`  
**제목**: 웹사이트 네비게이션  
**설명**: 메뉴 및 페이지 이동

**네비게이션 구성**:
```
상단 네비게이션 바
├─ 로고 (홈으로)
├─ 메뉴
│  ├─ 학습
│  ├─ 시험
│  ├─ 통계
│  ├─ 설정
│  └─ 파일 관리
└─ 정보 (버전, 도움말)
```

## 2. 비기능 요구사항 (NFR)

| ID | 요구사항 | 기준 |
|----|---------|------|
| **NFR-001** | 페이지 로드 시간 | < 2초 |
| **NFR-002** | 브라우저 호환성 | Chrome, Firefox, Edge (최신) |
| **NFR-003** | 반응형 디자인 | 모바일 (480px+), 태블릿, 데스크톱 |
| **NFR-004** | 데이터 자동 저장 | 매 작업 후 자동 저장 |
| **NFR-005** | 오류 메시지 | 한국어, 명확한 설명 |
