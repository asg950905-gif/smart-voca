## 1. PyQt6 기술 환경

### 1.1 PyQt6 개요
```
PyQt6 = Python + Qt6 바인딩
├─ Qt6: 크로스플랫폼 C++ GUI 프레임워크
├─ PyQt6: Python에서 Qt6 사용 가능
└─ Windows 네이티브 룩앤필
```

### 1.2 PyQt6의 특징

| 특징 | 설명 |
|------|------|
| **크로스플랫폼** | Windows, macOS, Linux 지원 |
| **네이티브 UI** | 각 OS의 네이티브 느낌 |
| **풍부한 위젯** | 버튼, 입력창, 테이블, 트리 등 |
| **레이아웃 관리** | 자동 위젯 배치 |
| **스타일링** | CSS 유사 문법 지원 |
| **다크모드** | 내장 지원 |
| **성능** | C++로 컴파일되어 빠름 |

## 2. PyQt6 vs PyQt5 vs 다른 프레임워크 비교

### 2.1 PyQt6 vs PyQt5

| 항목 | PyQt5 | PyQt6 |
|------|-------|-------|
| **Qt 버전** | Qt5 | Qt6 |
| **라이센스** | GPL/상용 | GPL/상용 |
| **신규 기능** | 기본 | 향상됨 |
| **유지보수** | 장기 지원 | 활발함 |
| **성능** | 우수 | 더 우수 |
| **학습곡선** | 낮음 | 낮음 |
| **마이그레이션** | - | PyQt5에서 쉬움 |

**선택 이유**: 최신 기술, 더 나은 성능, 향상된 기능

### 2.2 PyQt6 vs Tkinter

| 항목 | Tkinter | PyQt6 |
|------|---------|-------|
| **학습 난이도** | 매우 쉬움 | 중간 |
| **기능** | 기본만 | 매우 풍부 |
| **UI 품질** | 낮음 | 높음 |
| **커뮤니티** | 작음 | 큼 |
| **프로젝트 규모** | 소규모 | 모든 규모 |

**비교**: Tkinter는 간단한 도구용, PyQt6는 전문적 앱용

### 2.3 PyQt6 vs WinForms (C#)

| 항목 | PyQt6 | WinForms |
|------|-------|----------|
| **플랫폼** | 크로스 | Windows만 |
| **언어** | Python | C# |
| **개발 속도** | 빠름 | 중간 |
| **학습곡선** | 중간 | 낮음 |

**비교**: Python 환경에서는 PyQt6가 최선

## 3. PyQt6 핵심 개념

### 3.1 메인 컴포넌트

| 컴포넌트 | 역할 |
|----------|------|
| **QApplication** | 앱 시작, 이벤트 루프 |
| **QMainWindow** | 메인 윈도우 (메뉴바, 툴바 등) |
| **QWidget** | 기본 위젯 클래스 |
| **QLayout** | 위젯 배치 (VBox, HBox, Grid) |
| **Signal/Slot** | 이벤트 처리 메커니즘 |

### 3.2 주요 위젯 (smart-voca에서 사용)

```
┌─ QMainWindow
│  ├─ QMenuBar (메뉴: 파일, 편집, 도움말)
│  ├─ QToolBar (빠른 아이콘 버튼)
│  ├─ Central Widget
│  │  ├─ QTabWidget (탭: 학습, 시험, 통계)
│  │  │  ├─ StudyTab
│  │  │  ├─ TestTab
│  │  │  └─ ReportTab
│  │  └─ QStatusBar (상태바: 현재 일차, 학습 상태)
│  └─ QDockWidget (사이드 패널: 설정)
```

### 3.3 Signal/Slot (이벤트 처리)

```python
# 버튼 클릭 이벤트
button.clicked.connect(self.on_button_clicked)

# 입력창 텍스트 변경
input_field.textChanged.connect(self.on_text_changed)

# 사용자 정의 신호
self.progress_updated.emit(current_day)
```

## 4. smart-voca v2.0 UI 구조 설계

### 4.1 메인 윈도우 레이아웃

```
┌──────────────────────────────────────┐
│  File  Edit  View  Help              │ ← QMenuBar
├────────────────────────────────────────
│ [♻] [📚] [📊] [⚙️]                   │ ← QToolBar
├────────────────────────────────────────
│                                       │
│  ┌─────────────────────────────────┐ │
│  │ [학습] [시험] [통계] [설정]      │ │ ← QTabWidget
│  ├─────────────────────────────────┤ │
│  │                                 │ │
│  │     Tab Content 영역            │ │ ← Central Widget
│  │    (각 탭별 다양한 위젯)       │ │
│  │                                 │ │
│  │                                 │ │
│  └─────────────────────────────────┘ │
│                                       │
├──────────────────────────────────────┤
│ 1일차 | 완료율: 5% | 오늘 완료: O   │ ← QStatusBar
└──────────────────────────────────────┘
```

### 4.2 각 탭의 주요 기능

#### 학습 탭 (StudyTab)
```
[진도 정보]
├─ 현재: 1일차 / 30일차
├─ 완료율: 5%
└─ 오늘 학습: 10단어

[오늘의 단어]
├─ 단어 표시 (큰 폰트)
├─ 암기 여부 (O/X 버튼)
└─ 진도 바

[통계]
├─ 오늘 암기율: 80%
└─ 총 암기: 150/2000
```

#### 시험 탭 (TestTab)
```
[시험 설정]
├─ 문제 수: [    ] (스핀박스)
├─ 출제 모드: [한->영 ▼]
├─ 출제 형식: [혼합 ▼]
└─ [시험 시작] 버튼

[시험 진행]
├─ 진행 상태: 3/10
├─ 문제: "사과"는 영어로?
├─ [apple] [apricot] [orange] [banana]
└─ [다음] 버튼
```

#### 통계 탭 (ReportTab)
```
[학습 통계]
├─ 학습 진도: [████░░░░░░] 50%
├─ 암기 성공률: [██████░░░] 75%
└─ 시험 평균: [███████░░░] 78점

[그래프]
├─ 최근 7일 성적 추이 (라인 차트)
├─ 약점 단어 TOP10 (막대 차트)
└─ 학습 시간대별 분포 (파이 차트)
```
