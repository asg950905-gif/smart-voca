## 사전 준비 (시연 30분 전)
1. `git pull` 로 최신 코드 받기 → `pip install -r requirements.txt`
2. `python -m pytest tests -q` — 전부 통과 확인
3. `python ai-agent/scripts/시연데이터생성.py --reset` — 항상 같은 샘플 화면(고정 시드)
4. `python app.py` 실행 후 브라우저 창 2개 준비 (일반 창 = 사용자, 시크릿 창 = 관리자. 로그인 세션이 분리됨)
5. 인터넷 없이도 차트가 나오는지 확인 (Chart.js 는 `static/vendor/` 로컬 파일)
6. 브라우저 확대 100%, 알림·메신저 끄기

## 시연 흐름
> v2(UI 업그레이드) 추가 단계: **0)** 로그인 전 `/` 랜딩 → 빈칸 퀴즈 체험 → '로그인'. **3)** 학습 카드의 🔊 로 발음 듣기(소리가 나는 PC에서). **4)** 시험 형식에서 '✏️ 빈칸 채우기' 선택 → 정답 시 체크·컨페티·XP. **5-1)** 상단 '리그' 메뉴에서 주간 순위 시연. 홈에서는 레벨·XP·오늘 목표 링을 보여줄 것.

| 순서 | 화면 | 보여줄 것 | 말할 포인트 |
| :--- | :--- | :--- | :--- |
| 1 | 로그인/가입 | `minsu / demo1234` 로그인 (또는 새 계정 가입) | 가입자는 항상 일반 사용자, 관리자는 별도 |
| 2 | 사용자 홈 | 연속 학습일, 진도 링, 학습/마스터 단어 | 개인별 진도가 분리 저장됨 |
| 3 | 학습 | 플립카드 → 알아요/헷갈려요 (키보드 단축키) | 헷갈린 단어가 다음 학습·시험에 우선 출제 |
| 4 | 시험 | 4지선다/OX/단답 → 즉시 피드백 → 결과 | 정답은 서버에만 있고 채점 후 전달 |
| 5 | 통계 | 성공률 추이, 시험 점수, 자주 틀리는 단어 | |
| 6 | 다크모드·모바일 | 🌙 토글, 브라우저 폭 390px | 반응형 + 하단 탭바 |
| 7 | 관리자 로그인 | `admin / admin1234` (시크릿 창) | 청록색 + ADMIN 배지로 영역 구분 |
| 8 | 관리자 대시보드 | 전체 사용자 활동·평균 점수·어려운 단어·랭킹 | 사용자 학습 기록이 실시간 집계 |
| 9 | 단어 관리 | 단어 추가 → 검색 → CSV 가져오기 | 추가 즉시 사용자 학습에 반영 |
| 10 | 사용자 관리 | 비활성화 → (사용자 창에서 새로고침 시 로그아웃) | 권한·계정 통제 |
| 11 | 권한 확인 | 사용자 창에서 `/admin/` 접속 → 403 | 역할 기반 접근 제어 |

## 예상 질문 대비
- **Q. 동시 접속은?** 시험 진행 상태·학습 기록이 모두 사용자별로 DB 에 저장되어 섞이지 않는다(자동 테스트로 검증).
- **Q. 보안은?** 비밀번호 해시, CSRF 토큰, 로그인 5회 실패 시 5분 잠금, 관리자 API 권한 검사, 업로드 용량·형식 제한.
- **Q. 11/16 배포는?** 시연은 로컬, 배포 대상(서버·HTTPS·운영 DB 백업)은 별도 결정 필요.

## 비상 대응
- 화면이 비어 보임 → `시연데이터생성.py --reset` 재실행 후 서버 재시작
- 로그인 안 됨(잠금) → 5분 대기 또는 서버 재시작(메모리 잠금 초기화)
- 포트 충돌 → `$env:PORT=5001; python app.py`
- 최후 수단: 시연 영상 (미리 녹화해 두기 권장)

## 리허설 결과 (2026-11-02, Edge 헤드리스 자동 리허설)
시나리오 1~11 단계를 사용자 창·관리자 창 2개로 동시에 진행해 약 24초 안에 완주. JS 오류 없음(의도한 403 제외).

| 확인 항목 | 결과 |
| :--- | :--- |
| 신규 가입 → 데이터 없는 첫 화면(홈·통계 빈 상태 안내) | 정상 |
| 학습(키보드 단축키) → 시험(4지선다·OX·단답 모두 출제, Enter 로 다음 문제) | 정상 |
| 관리자 CSV 가져오기 (99 → 102개, 토스트 안내) | 정상 |
| 사용자 비활성화 → 사용자 창 새로고침 시 로그아웃 + 사유 안내 | 정상 (리허설 후 수정) |
| 비활성 계정 로그인 시 안내 문구 / 일반 사용자의 `/admin/` → 403 | 정상 |

**리허설에서 발견해 수정한 문제**
1. 모바일 관리자 상단바에서 "스마트 보카"가 세로로 깨지고 배지가 글자 단위로 줄바꿈 → 좁은 화면에서 로고+배지만 표시, 배지 줄바꿈 방지.
2. 일반 사용자의 403 화면에 관리자 메뉴·ADMIN 배지 노출 → 실제 관리자에게만 관리자 영역 표시.
3. 비활성화된 사용자가 설명 없이 로그인 화면으로 이동 → 안내 문구 표시.
4. 시험 결과의 오른쪽 값에 라벨이 없음 → "정답: … · 내 답: …" 표기.
(2·3번은 회귀 테스트를 추가했고, 1·4번은 화면 문제라 브라우저 캡처로 확인)

**시연 시 유의점**
- 신규 가입 시연을 하면 사용자가 추가되므로, 반복 시연 전에는 `시연데이터생성.py --reset` 으로 초기화.
- 시험 점수는 정답을 직접 고르면 올라간다 (자동 리허설은 첫 보기를 눌러 점수가 낮음). 시연자는 일부러 정답을 고를 것.
- 모바일 폭 시연은 브라우저 개발자도구(F12) → 기기 툴바에서 390px.
