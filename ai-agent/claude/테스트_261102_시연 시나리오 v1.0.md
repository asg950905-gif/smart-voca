## 사전 준비 (시연 30분 전)
1. `git pull` 로 최신 코드 받기 → `pip install -r requirements.txt`
2. `python -m pytest tests -q` — 전부 통과 확인
3. `python ai-agent/scripts/시연데이터생성.py --reset` — 항상 같은 샘플 화면(고정 시드)
4. `python app.py` 실행 후 브라우저 창 2개 준비 (일반 창 = 사용자, 시크릿 창 = 관리자. 로그인 세션이 분리됨)
5. 인터넷 없이도 차트가 나오는지 확인 (Chart.js 는 `static/vendor/` 로컬 파일)
6. 브라우저 확대 100%, 알림·메신저 끄기

## 예상 질문 대비
- **Q. 동시 접속은?** 시험 진행 상태·학습 기록이 모두 사용자별로 DB 에 저장되어 섞이지 않는다(자동 테스트로 검증).
- **Q. 보안은?** 비밀번호 해시, CSRF 토큰, 로그인 5회 실패 시 5분 잠금, 관리자 API 권한 검사, 업로드 용량·형식 제한.
- **Q. 11/16 배포는?** 시연은 로컬, 배포 대상(서버·HTTPS·운영 DB 백업)은 별도 결정 필요.

## 비상 대응
- 화면이 비어 보임 → `시연데이터생성.py --reset` 재실행 후 서버 재시작
- 로그인 안 됨(잠금) → 5분 대기 또는 서버 재시작(메모리 잠금 초기화)
- 포트 충돌 → `$env:PORT=5001; python app.py`
- 최후 수단: 시연 영상 (미리 녹화해 두기 권장)
