## 2. Flask 라우트 구조

### 2.1 기본 라우트

```python
# app.py

@app.route('/', methods=['GET'])
def home():
    """메인 대시보드"""
    return render_template('dashboard.html', ...)

@app.route('/api/progress', methods=['GET'])
def api_get_progress():
    """진도 정보 (JSON)"""
    return jsonify(study_manager.get_progress_info())

@app.route('/upload', methods=['POST'])
def upload_file():
    """CSV 파일 업로드"""
    file = request.files['file']
    word_manager.load_words_from_file(file)
    return redirect('/')
```

### 2.2 학습 관련 라우트

```python
@app.route('/study', methods=['GET'])
def study_page():
    """학습 페이지"""
    return render_template('study.html', ...)

@app.route('/api/study/daily-words', methods=['GET'])
def api_get_daily_words():
    """오늘의 단어 (JSON)"""
    return jsonify(study_manager.get_daily_words())

@app.route('/api/study/record', methods=['POST'])
def api_record_study():
    """학습 결과 저장"""
    data = request.json
    study_manager.record_study(data['words'], data['results'])
    return jsonify({'status': 'success'})
```

### 2.3 시험 관련 라우트

```python
@app.route('/test', methods=['GET'])
def test_page():
    """시험 페이지"""
    return render_template('test.html', ...)

@app.route('/api/test/configure', methods=['POST'])
def api_configure_test():
    """시험 설정"""
    config = request.json
    test_engine.configure_test(config)
    return jsonify({'status': 'success'})

@app.route('/api/test/next-problem', methods=['GET'])
def api_next_problem():
    """다음 문제"""
    return jsonify(test_engine.get_current_problem())

@app.route('/api/test/submit-answer', methods=['POST'])
def api_submit_answer():
    """답변 제출 및 채점"""
    data = request.json
    is_correct = test_engine.grade_answer(data['answer'])
    return jsonify({'is_correct': is_correct, 'explanation': ...})

@app.route('/api/test/finish', methods=['POST'])
def api_finish_test():
    """시험 완료"""
    test_engine.record_test()
    return jsonify(test_engine.get_results())
```

### 2.4 통계 관련 라우트

```python
@app.route('/report', methods=['GET'])
```

### 2.5 설정 관련 라우트

```python
@app.route('/settings', methods=['GET'])
def settings_page():
    """설정 페이지"""
    return render_template('settings.html', ...)

@app.route('/api/settings', methods=['GET', 'POST'])
def api_settings():
    """설정 조회/저장"""
    if request.method == 'POST':
        config_manager.save_settings(request.json)
        return jsonify({'status': 'success'})
    else:
        return jsonify(config_manager.get_settings())

@app.route('/api/settings/reset', methods=['POST'])
def api_reset_settings():
    """데이터 초기화"""
    config_manager.reset_data()
    return jsonify({'status': 'success'})
```

## 6. 데이터 흐름 예시

### 6.1 학습 페이지 흐름

```
1. 사용자 /study 방문
   ↓
2. study.html 렌더링
   ↓
3. JavaScript: fetch('/api/study/daily-words')
   ↓
4. Flask: StudyManager.get_daily_words()
   ↓
5. 첫 번째 단어 표시
   ↓
6. 사용자 O/X 선택
   ↓
7. JavaScript: fetch('/api/study/record', {...})
   ↓
8. Flask: StudyManager.record_study()
   ↓
9. CSV/JSON 저장
   ↓
10. 다음 단어 로드
```

## 7. 예외 처리

```python
try:
    words = word_manager.load_words()
except FileNotFoundError:
    return jsonify({'error': '파일을 찾을 수 없습니다'}), 404
except ValueError:
    return jsonify({'error': '파일 형식이 올바르지 않습니다'}), 400
except Exception as e:
    logger.error(f"Error: {e}")
```
