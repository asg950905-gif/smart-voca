## 사전 준비 (시연 30분 전)
1. `git pull` 로 최신 코드 받기 → `pip install -r requirements.txt`
2. `python -m pytest tests -q` — 27개 전부 통과 확인
3. `python ai-agent/scripts/시연데이터생성.py --reset` — 항상 같은 샘플 화면(고정 시드: 토익 단어 2,283개(`ai-agent/scripts/words_toeic.csv`), 학습자 5명 — 11/9 에 2명 추가). **실사용 데이터가 있는 DB 에서는 금지**
4. `python app.py` 실행 후 브라우저 창 2개 준비 (일반 창 = 사용자, 시크릿 창 = 관리자. 로그인 세션이 분리됨)
5. 인터넷을 끊고도 차트·아이콘이 나오는지 확인
6. 브라우저 확대 100%, 알림·메신저 끄기, **소리 켜기**(학습 카드 자동 발음)
7. 랜딩 수치 확인: 등록 단어 2,283 / 학습자 5 / 누적 학습 1,060 / 시험 응시 34 (reset 직후 기준, 11/13 토익 단어 반영 후). 시연 계정: `minsu`, `jiyoung`, `hojun`, `seoyun`, `taeho` (모두 `demo1234`)

- 실습실 PC 의 `/static/js/main.js` Content-Type 은 이 PC 에서만 확인(정상). 실습실에서 재확인 필요.
- 확인 범위는 Edge(Chromium). 다른 브라우저는 미확인.

**시연 시 유의점**
- 신규 가입 시연을 하면 사용자가 추가되므로, 반복 시연 전에는 `시연데이터생성.py --reset` 으로 초기화.
- 시험 점수는 정답을 직접 고르면 올라간다 (자동 리허설은 첫 보기를 눌러 점수가 낮음). 시연자는 일부러 정답을 고를 것.
- 모바일 폭 시연은 브라우저 개발자도구(F12) → 기기 툴바에서 390px.
