**파일 위치**: `ai-agent/claude/설계_261111_인터페이스정의_v1.0.md`
**작성일**: 2026-11-11
**버전**: v1.0
**설명**: 컴포넌트·컨테이너 간 통신 명세. HTTP API 엔드포인트, 요청/응답 스키마, 상태 코드. 현행 코드(`src/web/`, `src/api/`)로부터 역분석.

---

## 0. API 설계 원칙

1. **RESTful**: 리소스 중심 (명사), 동작 중심 (HTTP 메서드)
2. **JSON**: 모든 API는 JSON 요청/응답 (단, 파일 업로드는 multipart/form-data)
3. **상태 코드**: 표준 HTTP 상태 코드 (200, 201, 400, 403, 404, 500 등)
4. **CSRF 보호**: 상태 변경(POST/PUT/DELETE)은 CSRF 토큰 필수
5. **권한**: 401(미인증), 403(미인가)으로 명확히 구분

---

## 1. 기본 설정

### 1.1 Base URL

```
http://127.0.0.1:5000  (개발 환경)
또는 배포 환경 도메인
```

### 1.2 인증

**세션 기반**:
- 로그인 후 세션 쿠키 (HttpOnly, SameSite=Lax)
- 모든 요청에 자동 첨부

**CSRF 토큰**:
- Header: `X-CSRF-Token`
- 또는 Form: `csrf_token`
- POST/PUT/DELETE 요청에 필수

### 1.3 응답 형식

**성공 (200, 201)**:
```json
{
  "status": "success",
  "data": { ... }  // 또는 배열, 또는 스칼라값
}
```

**오류**:
```json
{
  "status": "error",
  "error": "오류 메시지"
}
```

또는 HTTP 상태 코드만 (GET 조회시 등)

## 2. 인증 API (Authentication)

### 2.1 POST /api/auth/register

**설명**: 회원가입

**요청**:
```json
{
  "username": "minsu",
  "password": "demo1234",
  "password_confirm": "demo1234"
}
```

**응답 (200)**:
```json
{
  "status": "success",
  "message": "회원가입이 완료되었습니다."
}
```

**응답 (400)**:
```json
{
  "status": "error",
  "error": "아이디는 3~20자 영문/숫자/밑줄만 가능합니다."
}
```

또는:
```json
{
  "status": "error",
  "error": "이미 사용 중인 아이디입니다."
}
```

**관련 요구사항**: FR-101

---

### 2.2 POST /login (HTML 폼)

**설명**: 로그인 (폼 기반, API 아님)

**요청** (multipart/form-data):
```
username=minsu
password=demo1234
csrf_token=...
```

**응답 (302 리다이렉트)**:
- 성공: `/` (사용자) 또는 `/admin/` (관리자)
- 실패: `/login` (오류 메시지 포함)

**관련 요구사항**: FR-102, FR-104, FR-105

---

### 2.3 POST /logout (HTML 폼)

**설명**: 로그아웃

**요청** (multipart/form-data):
```
csrf_token=...
```

**응답 (302 리다이렉트)**:
- `/login` (로그인 페이지)

**관련 요구사항**: FR-103

## 9. 상태 코드 정의

| 코드 | 의미 | 예시 |
|------|------|------|
| **200** | OK | 성공적 GET, PUT |
| **201** | Created | 새 리소스 생성 (POST) |
| **400** | Bad Request | 형식 오류, 검증 실패 |
| **401** | Unauthorized | 로그인 필수 |
| **403** | Forbidden | 권한 부족 (관리자만) |
| **404** | Not Found | 리소스 없음 |
| **413** | Payload Too Large | 파일 크기 초과 (3MB) |
| **500** | Internal Server Error | 서버 오류 |
