# utils — 설정 관리

**파일 위치**: `src/utils/README.md`
**작성일**: 2026-11-02
**버전**: v1.0
**설명**: 사용자 개인 설정과 관리자 전역 설정을 검증·저장한다.

---

## 파일
| 파일 | 클래스 | 내용 |
| :--- | :--- | :--- |
| `config.py` | `SettingsManager`, `SettingsError` | 개인 설정, 전역 설정, 허용 범위 검증 |

## 설정 두 종류
| 구분 | 저장 위치 | 항목 | 누가 변경 |
| :--- | :--- | :--- | :--- |
| 개인 | `users` 테이블 컬럼 | 하루 학습 단어 수(`daily_target`), 테마(`system/light/dark`) | 본인 |
| 전역 | `app_settings` 테이블 | 목표 일수(`total_days`), 시험 최대 문항(`max_test_problems`), 하루 학습량 상한(`max_daily_target`) | 관리자 |

## 설계 이유
- **허용 범위를 코드에 둔다** (`GLOBAL_LIMITS`): 화면의 입력 제한(`min`/`max`)만 믿지 않고 **서버에서 다시 검증**한다. 브라우저 검증은 우회될 수 있다.
- **부분 저장을 허용**한다: 테마 토글은 `theme` 만 보내도 되고, 없는 항목은 현재 값을 유지한다.
- 관리자가 정한 **상한이 사용자 설정보다 우선**한다 (예: 상한 30이면 사용자는 31을 저장할 수 없음).

## 예상 질문
- **Q. 왜 설정 파일(JSON)이 아니라 DB?** 개인 설정은 사용자별이고 관리자가 화면에서 바꾸므로 DB 가 일관적이다. 파일 설정은 동시 수정 문제가 있다.
